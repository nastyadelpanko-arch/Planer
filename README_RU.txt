МОЙ ПЛАНЕР — Android-проект

В проекте уже есть приложение-планер с русским интерфейсом. Оно хранит задачи локально на телефоне и не требует сайта/HTTPS. Мотивационные фразы нейтральные, без привязки к гендеру.

Важно: это исходный Android-проект, а не готовый APK. В этой рабочей среде нет Android SDK/Gradle, поэтому я не могу честно приложить уже собранный APK. Проект настроен так, чтобы GitHub автоматически собрал APK.

Как получить APK через GitHub:
1. Распакуйте ZIP.
2. Создайте новый репозиторий на GitHub.
3. Загрузите в репозиторий ВСЁ содержимое распакованной папки, включая папку .github.
4. Откройте вкладку Actions. Если GitHub попросит разрешить Actions, подтвердите.
5. Выберите workflow “Build Android APK” и нажмите Run workflow (или дождитесь сборки после загрузки файлов).
6. Когда запуск завершится зелёной галочкой, откройте его и внизу раздел Artifacts. Скачайте moy-planer-apk.zip и распакуйте его.
7. Внутри будет app-debug.apk. Откройте его на Android и разрешите установку из этого источника, если телефон попросит.

Приложение работает офлайн. Данные хранятся на этом устройстве; очистка данных приложения может удалить задачи. В настройках планера есть экспорт/импорт резервной копии.
